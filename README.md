# 外贸客户信息整理工具

一个简洁的浏览器客户数据工作台：将不同格式的外贸客户表映射到统一结构，人工校对，再导出 Excel 或 CSV。

## 功能

- 批量选择或拖放 XLSX、XLS、CSV、TSV、ODS，单文件上限 20 MB。
- 每份文件独立选择工作表、表头行和字段映射；自动识别常见中英文表头。
- 客户名称（兼容原“联系人”）、公司名、邮箱为固定字段，不可删除；电话、国家 / 地区、产品需求、网站、备注等可删除。
- 在“字段设置”中新增自定义字段，例如采购数量、客户等级。映射、表格编辑、搜索、模板和 Excel/CSV 导出同步使用当前字段。
- CSV / TSV 支持 UTF-8、GB18030 / GBK、UTF-16 LE 编码选择。
- 编辑单元格、新增客户、批量删除、搜索、分页、待完善和疑似重复提示。
- 表头之后的非空记录不再因映射结果为空而被跳过。客户名称、公司名、邮箱任意一项为空时，单独进入“缺少主体”，提示实际缺项，保留原始非空单元格供查看、搜索和导出；完全空白的行仍跳过。
- 在“缺少主体”补齐三个固定字段后，勾选记录并点击右上角的“加入全部客户”。青蓝色实心按钮与新增、删除操作并列，显示可加入数量；批量操作仅加入所选记录中已补齐的部分，未补齐的继续保留。确认前保持在该分类，不计入全部客户、待完善或疑似重复；任意固定字段再次清空时，会重新进入缺少主体。
- 客户资料库可选择每页显示 10、25、50 或 100 条（默认 25 条），显示当前记录范围；切换数量、搜索或筛选时回到第一页，表头勾选只选择当前页。
- 青蓝色界面，统一线性图标；按钮提供悬浮变色与键盘焦点反馈，适配手机窄屏。
- 导出全部记录到 XLSX / CSV，附带来源、原始行号、校对提示和记录分类；保留缺少主体记录的原始内容。
- 内置虚构示例数据及空白标准模板。响应式界面，保留工具名称 Banner。

## 使用

直接打开 `dist/index.html`，或安装 Node.js 后执行：

```sh
node server.cjs
```

浏览器访问 http://127.0.0.1:4173 。无需安装 npm 依赖，无需后端、账号或 API Key。

1. 导入文件，选择工作表和表头行。
2. 核对自动映射，手动调整未识别的列，点击“添加到客户列表”。多张工作表请分别添加。
3. 在“缺少主体”查看原始内容并补齐固定字段，勾选记录后点击右上角“加入全部客户”（可批量处理）；再按“待完善”“疑似重复”校对。最后导出客户表。

导出包含所有保留记录，不受当前搜索、筛选或分页影响。Excel 使用“客户资料”“缺少主体”两个数据表，并在有原始内容时附带“主体补充原始内容”表（每个原始非空单元格一行）；CSV 通过“记录分类”区分，并将原始内容保存在同一行的 JSON 文本中。补充并加入全部客户后，原始内容仍保留。导出文件不是完整工作项目备份，重新导入不会自动还原分组确认状态。

疑似重复仅提示，不会自动删除；同一来源的同一工作表不能重复添加。再次选择相同文件视为新来源，可能出现重复记录提示。

## 缺少主体与待完善规则

空白按去除首尾空格后的文本判断。“缺少主体”的条件是**公司名、客户名称、邮箱任意一项为空**；电话、需求或自定义字段有内容也不能代替固定字段。三项补齐后须勾选记录，并明确点击右上角“加入全部客户”，然后再按下列规则检查。导入时三项已齐全的记录直接进入全部客户。

“待完善”检查已加入全部客户的记录，目前仅有以下一条规则：

| 提示 | 判断条件 |
| --- | --- |
| 邮箱格式待核对 | 邮箱非空但不符合基本格式；按中英文逗号、分号或换行分隔后，每一项都需符合格式 |

固定字段缺失统一归入“缺少主体”，不再计入待完善。邮箱有内容但格式异常不会阻止加入全部客户，加入后列为待完善；多个邮箱中任意一个格式异常就触发提示。电话、国家、产品需求、网站、备注和自定义字段为空不触发待完善；疑似重复另行提示。当前不验证电话格式、电话真实性、邮箱可投递性或客户真实性。“可用”仅表示通过现有基础检查。

字段设置仅在本次页面会话内有效，刷新后恢复默认。建议先设置字段再导入；已有客户新增字段时初始为空，可手动填写。删除包含数据的字段会先确认，确认后移除该字段内容及所有文件中的对应映射。字段名不能为空、重复或使用系统列名，最长 30 字符，总数上限 40。“固定字段”不可删除，且加入全部客户前必须全部填写。

## 数据与边界

客户数据只在当前页面内存中处理，不向服务器上传、不存储到 localStorage。刷新或关闭前请导出；有未导出修改时会触发浏览器离开提示。此版本不提供云同步或多用户协作。支持最多 50,000 条客户记录，大文件建议分批处理。密码保护文件需要先解密。

电话以显示文本读取并以文本导出，保留原表已有的前导零和国际区号；原文件中已丢失的信息无法还原。CSV 为防止公式注入，对公式前缀添加单引号；XLSX 输出文本单元格。源公式只读取已有显示值，不执行宏和公式。

## 技术与验证

原生 HTML / CSS / JavaScript，无构建步骤。Excel 解析使用本地内置 SheetJS CE 0.20.3（Apache-2.0）；部署后无需请求第三方 CDN。

```sh
node --test tests/*.test.cjs
```

`dist/` 可部署到任意静态托管服务。GitHub Pages 可用仓库内的手动部署工作流：先在 Settings → Pages 中选择 GitHub Actions，再在 Actions 运行 Deploy static site。未启用 Pages 前仅上传源码不会产生公开网页。

## 文件结构

```text

dist/vendor/          内置解析库及第三方许可证
tests/               数据处理测试
server.cjs           本地静态预览服务器
```
